# Keepsake — Responsive Landing Page

Лабораторна робота №7, завдання 4–5.

## Опис проєкту

Keepsake — адаптивний односторінковий сайт дизайн-агенції, розроблений відповідно до макета Figma.

## Використані технології

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Custom Properties
- Media Queries
- Google Fonts
- GitHub Pages

## Функціональність

- Адаптивна верстка за принципом Mobile First.
- Підтримка мобільних пристроїв, планшетів та комп'ютерів.
- Фільтрація робіт портфоліо за категоріями.
- Мобільне навігаційне меню.
- Hover та Focus ефекти.
- Форма підписки з HTML-валідацією.
- Плавна прокрутка сторінки.
- Оптимізовані зображення WebP та inline SVG.

Проєкт реалізовано без JavaScript та сторонніх CSS-фреймворків. Форма підписки демонстраційна, без серверної обробки.

## Запуск проєкту

Відкрити файл `index.html` у браузері або за допомогою розширення Live Server у VS Code.
