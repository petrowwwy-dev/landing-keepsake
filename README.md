# Keepsake — лабораторна робота №7, завдання 4–5

Адаптивний односторінковий сайт за [макетом Figma](https://www.figma.com/design/zU2RnSTEKaooZsBckA3ynm/). HTML5, CSS, Flexbox, CSS Grid для портфоліо, mobile first (768 і 1280 px), CSS-змінні, Google Fonts із display=swap. Без JavaScript та фреймворків.

Зображення експортовані з Figma у PNG та конвертовані у WebP; іконки послуг експортовані як SVG і вставлені inline. Фільтр реалізований через :checked ~; мобільне меню — HTML Popover API. Форма демонстраційна: HTML-валідація, обов’язкова згода, CSS :target для повідомлення успіху. На десктопі всі дев’ять робіт уже показані, додаткових робіт у макеті немає. Кнопка відкриття й кнопка закриття меню мають окремі статичні aria-expanded; нативний Popover надає власну семантику стану. Соціальні посилання демонстраційні.


## Запуск
Відкрити index.html через Live Server.

## Демо (завдання 5)
Після публікації в репозиторії landing-keepsake додати сюди фактичне посилання GitHub Pages. Settings → Pages → Deploy from a branch → main → / (root) → Save.
